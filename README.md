# NUVÉ Studio

A responsive Korean-language creative studio landing page built with plain HTML, CSS, and JavaScript. No build step or runtime dependencies are required.

## Run locally

Open `index.html` directly in a modern browser, or serve this directory with any static file server.

## Files

- `index.html` — semantic page content and inline CSS/JS references
- `styles.css` — responsive visual system and CSS-generated project artwork
- `script.js` — accessible mobile navigation interactions

All typography uses system font fallbacks; all project artwork is generated with CSS.

## Accessibility and responsive behavior

The page includes a skip link, landmarks, semantic headings, keyboard-operable mobile navigation, reduced-motion support, and responsive layouts.
